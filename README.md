# Parla! — Italiano Coach

Webapp/PWA gratuite d'apprentissage de l'italien, pensée pour iPhone.

## V1
- 6 micro-leçons A1
- QCM et réponses écrites
- prononciation italienne via la synthèse vocale native
- XP et série quotidienne
- répétition espacée
- progression stockée localement
- fonctionnement hors ligne après la première visite
- aucune API payante

## iPhone
Après publication avec GitHub Pages, ouvrir l'URL dans Safari puis **Partager → Sur l'écran d'accueil**.

## Confidentialité
Aucune donnée d'apprentissage n'est envoyée à un serveur. La progression est conservée dans le stockage local du navigateur.
